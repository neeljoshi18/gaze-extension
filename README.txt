Gaze — Chrome extension
=======================

1. Unzip. Open the folder that contains manifest.json
   (GitHub zip → gaze-extension-main).
2. chrome://extensions → Developer mode on
3. Remove any old Gaze card, then Load unpacked → that folder
4. Open https://www.instagram.com/reels/
5. Click the top-left box if it says Tap to start camera, then Allow

Look down = next reel. Look up = previous.
Chip should read Calibrate, then Eyes or Face.

Camera is requested as Instagram (same as the site permission).
Video stays on your machine.
